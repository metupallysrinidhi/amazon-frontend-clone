<h1 align="center">Amazon Frontend Clone</h1>
<p align="center">
  A responsive Amazon homepage clone built with HTML & CSS
</p>
This project recreates the look and feel of Amazon's landing page, including the navigation bar, hero section, product categories, and footer.

##  Features

* Responsive navigation bar
* Amazon-style hero banner
* Product category boxes with images
* Styled footer section
* Organized project structure
* Clean and reusable CSS

##  Technologies Used

* HTML5
* CSS3
* Font Awesome

##  Project Structure

```text
amazon-frontend-clone/
│
├── required-images/
│   ├── box1.jpg
│   ├── box2.jpg
│   ├── ...
│
├── project-index.html
├── project-index.css
└── README.md
```




##  How to Run

1. Clone the repository:

```bash
git clone https://github.com/metupallysrinidhi/amazon-frontend-clone.git
```

2. Open the project folder.

3. Open `project-index.html` in your browser or use VS Code Live Server.
